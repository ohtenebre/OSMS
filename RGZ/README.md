# Расчётно-графическое задание  
**Тема:** Моделирование полного цикла передачи данных в системе мобильной связи

## Цель работы
1. Объединить знания и навыки, полученные в лабораторных работах №3–№5, в единую систему передачи данных.
2. Реализовать полный цикл обработки сигнала: от кодирования текста до его восстановления на приёмной стороне.
3. Применить методы синхронизации, помехоустойчивого кодирования и цифровой модуляции в условиях зашумленного канала.

## Ход работы

### 1. Исходные данные
- Имя и фамилия: **Rubcov Roman** (латиницей)
- Порождающий полином CRC (из ЛР №5):  
  $$ G(x) = x^7 + x^6 + x^5 + x^3 + x^2 + x + 1 $$
  → двоичное представление: `11101110`
- Последовательность Голда (из ЛР №4):  
  генератор на основе двух 5-разрядных LFSR → длина (G = 31) бит
- Количество отсчётов на бит: (N = 8)
- Уровень шума: ($\sigma$ = 6)
- Временной сдвиг: 900 отсчётов

### 2. Этапы реализации (Python)
- **ASCII-кодирование**: строка преобразована в 88-битную последовательность.
- **CRC-кодирование**: к данным добавлен 7-битный CRC.
- **Синхронизация**: в начало добавлена 31-битная последовательность Голда.
- **Модуляция**: BPSK с \(N = 8\) отсчётами на бит (амплитуда ±100).
- **Моделирование канала**: сигнал вставлен со сдвигом 900 в нулевой массив, добавлен гауссовский шум (\($\sigma$ = 6\)).
- **Синхронизация на приёмной стороне**: корреляционный приём → найден стартовый индекс `900`.
- **Демодуляция**: пороговое решение по усреднённым отсчётам → восстановлены биты.
- **Проверка и декодирование**: CRC-проверка успешна → текст восстановлен как «Rubcov Roman».
- **Спектральный анализ**: построены спектры для \(N = 4, 8, 16\) — подтверждена обратная зависимость ширины спектра от длительности символа.

### 3. Визуализация
Выполнена визуализация всех ключевых этапов:
- битовая последовательность (ASCII)
- последовательность Голда
- BPSK-сигнал после модуляции
- сигнал со сдвигом
- зашумленный принятый сигнал
- сигнал после синхронизации
- восстановленные биты vs исходные
- спектры при разных \(N\)

### 4. Проверка корректности
- CRC на приёмной стороне: `[0,0,0,0,0,0,0]` → ошибок нет.
- Восстановленный текст полностью совпадает с исходным.

## Результаты
- Реализована и протестирована **полная система передачи данных**.
- Все этапы выполнены корректно: синхронизация, демодуляция, проверка CRC, декодирование.
- Исходное сообщение восстановлено без ошибок при заданном уровне шума.
- Подтверждено влияние длительности символа на спектр сигнала.
- Система демонстрирует работоспособность в реалистичных условиях.

## Запуск
1. Убедитесь, что установлены зависимости:
   ```bash
   pip install numpy matplotlib
   ```
2. Запустите скрипт:
   ```bash
   python3 main.py
   ```
3. Следуйте инструкциям в терминале:
   - Введите передаваемый текст латиницей (например, `Hello world!`)
   - Укажите сдвиг
   - Укажите уровень шума (например, `6`)

Скрипт автоматически:
- выполнит все этапы обработки,
- выведет результаты в терминал,
- отобразит все графики.
